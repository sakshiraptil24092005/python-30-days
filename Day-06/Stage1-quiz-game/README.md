Stage 1 – Quiz Game

Description

A simple command-line quiz game built using Python. It asks 10 questions, checks the answers, calculates the final score and percentage, and allows the player to play again.

Features

* 10 general knowledge questions
* Case-insensitive answers
* Score tracking
* Final score and percentage
* Messages based on performance
* Play-again option

Requirements

* Python 3 installed
* A terminal or command prompt

How to Run

1. Open the project folder in a terminal.
2. Run the following command:
    python quiz_game.py

Concepts Used

* Variables
* Lists and tuples
* while loop
* for loop
* if-elif-else conditions
* User input
* String methods: strip() and lower()
* Arithmetic operations
